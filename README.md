## 🚀 Projeto em Destaque

### Body Health Pro

Plataforma SaaS para gestão de composição corporal desenvolvida para profissionais de Educação Física.

O projeto nasceu para resolver uma necessidade real de uma profissional da área e evoluiu para uma solução completa de acompanhamento físico, permitindo o gerenciamento de clientes, avaliações corporais, dashboards comparativos e geração de relatórios.

### Principais Características

* Aplicação em produção
* Utilização em ambiente real
* Arquitetura Monorepo
* Multi-tenant
* Autenticação e autorização
* Row Level Security (RLS)
* Dashboards evolutivos
* Relatórios PDF
* Componentes compartilhados
* Regras de negócio centralizadas

### Stack

React • TypeScript • Supabase • PostgreSQL • Zod • Chart.js • jsPDF • Vercel

🔗 Demo: https://body-health-pro-admin.vercel.app

🔗 Repositório: https://github.com/helderrsantos/body-health-pro
